Drop out page

The Drop-out Page is used when a user reaches a point in a journey where they cannot continue. It provides a clear explanation of the outcome, why the decision has been made, and what options are available to the user next.

When to use this pattern

Use this pattern when a user is no longer able to proceed because they do not meet eligibility criteria or another business rule prevents them from continuing. It should be used when a definitive decision has been reached.

When not to use this pattern

Do not use this pattern for validation errors, missing information, or technical issues. If the user can continue by correcting an error or providing additional information, standard error handling should be used instead.

How it works

The page clearly communicates the outcome, the reason for the decision, and any information that contributed to it. Where appropriate, users should be given the option to review or change their answers, re-check eligibility, or follow any relevant next steps.
