Filter

A filter component helps users narrow down a list or dataset by selecting one or more criteria, so they can quickly find what is relevant to them.

When to use this component

Use the filter component when users need to narrow down a list or dataset by selecting one or more criteria. It is particularly useful on search results pages, data tables, and listing pages where there are many items to browse.

When not to use this component

Do not use the filter component when there are fewer than 5 items in a list — it adds unnecessary complexity. Do not use it as a substitute for search. Avoid using the filter on pages where users are completing a task or filling in a form.

How it works

The filter component appears as a panel on the left-hand side of the content area. It contains one or more groups of checkboxes or radio buttons, each with a clear group label. Users select their criteria and apply the filter using a button. Results update in the main content area. A 'Clear filters' link should always be available when filters are applied.

Accessibility

Ensure all filter controls have visible labels and are keyboard accessible. Use field set and legend elements to group related controls. Announce filter results dynamically using an ARIA live region so screen reader users are informed when the results update.
