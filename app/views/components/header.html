Ofgem header

The Ofgem header identifies the service as an official Ofgem digital service. It appears at the top of every page and includes the Ofgem logo and, where applicable, the service name.

When to use this component

Use the Ofgem header on all internal and customer-facing digital services. Always display the Ofgem logo on the left.

When not to use this component

Do not use this header for services that are hosted on GOV.UK — use the GOV.UK header instead.

How it works

The header uses the standard Ofgem orange logo mark and sets the service identity. Keep the header minimal — avoid adding icons, navigation, or additional branding elements unless specified in Ofgem guidance.

Accessibility

Ensure the Ofgem logo has descriptive alt text. The header landmark must be present on every page for screen reader navigation.
