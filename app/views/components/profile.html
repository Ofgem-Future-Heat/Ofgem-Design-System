Profile banner

The profile banner displays a summary of a user account or organisation at the top of account management pages. It typically shows the user or organisation name and key details at a glance.

When to use this component

Use the profile banner on account overview and profile pages where users need to see their account summary at a glance.

When not to use this component

Do not use the profile banner on transactional pages or forms — it can distract users from completing a task.

How it works

The profile banner spans the full width of the content area below the header. It contains the account name as a heading and can include secondary details such as account type or reference number. Use a light background to distinguish it from the main page content.

Accessibility

Ensure the profile banner is not a landmark — use a div rather than a header or section element. All text must meet minimum contrast ratios.
