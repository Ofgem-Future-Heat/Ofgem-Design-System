Multi file upload

The multi file upload component lets users select and upload multiple files at once. It provides a drag-and-drop area alongside a file picker, and allows users to remove files after uploading.

When to use this component

Use the multi file upload component when users need to submit more than one file as part of a form or task, for example, uploading supporting documents, evidence files, or images as part of an application or submission.

When not to use this component

Do not use the multi file upload component when users only need to upload a single file, use the file upload component from GOV.UK Design System instead.

How it works

The component displays a drop zone where users can drag files from their device, or click a button to open a file picker. Once files are added, each file is listed with its name, and size. Users can remove individual files from the list.

Accessibility

Ensure the drop zone is keyboard accessible and can be activated with Enter or Space. Upload status and error messages must be announced to screen readers using appropriate ARIA live regions. All interactive elements must meet minimum contrast ratios.
